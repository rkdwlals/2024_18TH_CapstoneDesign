# 휴대폰 카메라를 이용한 OpenCV 활용 아동 미세 운동 검사

아동이 그린 도형을 휴대폰 카메라로 찍으면, OpenCV로 윤곽선을 찾아 K-BOT-2 미세 운동 통합 채점 기준에 맞춰 점수를 매기고, 결과를 엑셀 검사지로 만드는 프로젝트입니다.

- 2024 캡스톤디자인, 팀 차일드 3인 (컴퓨터공학과·작업치료학과·메타버스&게임학과)
- 2024년 11월 캡스톤디자인경진대회 **동상**
- 언어·라이브러리: Python, OpenCV, NumPy, openpyxl, Pillow

## 내가 맡은 부분 (강지민)

### 1. 별 도형 채점 알고리즘 — `star.py`

아동이 그린 별 그림과 정답 별 그림을 같은 크기(1000×1000)로 맞춘 뒤 회색조 → 가우시안 블러 → 이진화 → Canny 엣지 순서로 전처리하고, 가장 큰 외곽선을 골라 5개 기준으로 1점씩 채점합니다.

| 기준 | 판정 방법 |
|---|---|
| 기본 모양 | `approxPolyDP`로 근사한 꼭짓점 개수가 10개(별의 바깥 5개·안쪽 5개)인지 |
| 닫힘 | 윤곽선 시작점과 끝점 사이 거리가 10px 이하인지 |
| 윤곽선 | 이웃한 꼭짓점 사이 길이 중 가장 긴 것이 가장 짧은 것의 1.5배 이하인지 |
| 방향 | 정답 윤곽선과의 `matchShapes` 값이 1.5 미만인지 |
| 전체 크기 | 그린 도형의 면적이 정답 면적의 50% 이상인지 |

결과는 "별 채점 결과: n/5점"과 기준별 획득 점수로 출력하고, 윤곽선과 꼭짓점을 표시한 이미지를 함께 보여 줍니다.

### 2. 엑셀 검사지 결과 — `WriteExcel.py`

검사자 이름·나이·나잇대 평균 점수·검사자 점수와 함께, 검사자가 그린 그림과 나잇대 평균 그림을 셀에 넣은 엑셀 검사지(`examiner_report.xlsx`)를 만듭니다. 현재 코드의 이름·점수는 동작 확인용 임시 값입니다.

### 3. 카카오톡 결과 알림 — `kakao_utils.py`, `send_alarm.py`, `asd.py`, `combine.py`

검사지를 만든 뒤 카카오톡 "나에게 보내기" API로 검사지 다운로드 안내 메시지를 보냅니다.

| 파일 | 내용 |
|---|---|
| `asd.py` | 인가 코드로 카카오 토큰을 처음 발급 |
| `kakao_utils.py` | 토큰 저장·불러오기·갱신, 메시지 전송 API 호출 |
| `send_alarm.py` | 엑셀 다운로드 안내 메시지(버튼 링크) 전송 |
| `combine.py` | 엑셀 검사지 생성과 카카오톡 전송을 한 파일로 합친 버전 |

메시지 속 다운로드 링크는 아직 자리 표시용 주소입니다. 실행하려면 Kakao Developers 앱 키와 토큰 파일(`kakao_token.json`)이 필요합니다. 토큰 파일은 개인 계정 정보가 들어 있어 저장소에서 지웠습니다.
